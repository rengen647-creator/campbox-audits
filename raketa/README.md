# Детский лагерь «Ракета» — персональное КП CampBox × TravelLine

## Файлы
- `index.html` — готовая автономная клиентская HTML-презентация, включая запись встречи.
- `tilda-t123.html` — код для блока **T123 / HTML-код** в Tilda.

## Адрес на GitHub Pages
https://rengen647-creator.github.io/campbox-audits/raketa/

## Публикация на Tilda
1. Создайте страницу `/raketa` (или используйте нужный адрес на сайте).
2. Добавьте стандартный блок **T123 / HTML-код**.
3. Вставьте **полное содержимое** `tilda-t123.html`.
4. Опубликуйте страницу и проверьте на компьютере и телефоне.
5. Изменения HTML в GitHub будут отображаться на странице после обновления GitHub Pages.

## Важные условия
- Клиентская страница размещена в публичном репозитории и доступна по прямой ссылке; `noindex` — только рекомендация поисковым системам, не защита доступа.
- Блок родительских документов и цены TravelLine являются частью коммерческого предложения. Источник цен TravelLine датирован 29.07.2026; перед заключением договора необходимо проверить актуальность и применимость условий.
- Камера и приватные записи не хранятся в репозитории; ссылка на запись ведёт на Яндекс Диск.
- Код Tilda проверяет отправителя и источник сообщений перед изменением высоты iframe.
- Сайт Tilda не публикуется автоматически из GitHub: сначала вставьте код и нажмите «Опубликовать» в Tilda.
