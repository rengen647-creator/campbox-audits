# «Звёздочка» — клиентский аудит CampBox

- **GitHub Pages:** https://rengen647-creator.github.io/campbox-audits/zvezdochka/
- **Готовая страница:** `index.html`
- **Код для вставки в Тильду:** `tilda-t123.html`

## Развёртывание
1. Дождитесь публикации `main` через GitHub Pages. Проверяйте публичный URL и доступность навигации.
2. На странице Tilda добавьте блок **T123 — HTML-код**.
3. Скопируйте целиком содержимое `tilda-t123.html` в HTML блока.
4. При необходимости отключите внешние отступы блока Tilda.
5. Опубликуйте страницу Tilda и проверьте адаптивность на смартфоне, смену разделов и печать PDF.

`index.html` сообщает родительской Tilda-странице высоту через `postMessage`; родительский код проверяет origin.

> Внимание: GitHub Pages публичен. Мета-тег `noindex` снижает вероятность индексации, но не делает аудит приватным. Публикация в GitHub не изменяет существующие страницы Tilda.
