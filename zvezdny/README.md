## Установка в Tilda
1. Убедиться, что GitHub Pages включён для `main / (root)` и по URL выше открывается именно «Звёздный». Если загрузка ещё не завершилась, дождаться завершения развёртывания.
2. Создать страницу Tilda, например `/zvezdny`, добавить **Другое → T123 HTML-код**.
3. Скопировать **весь** `tilda-t123.html` в код блока. Не вставлять `index.html` напрямую.
4. В настройках блока убрать внешние отступы сверху/снизу; опубликовать страницу Tilda.
5. На опубликованном URL проверить навигацию по кнопкам, обе ссылки на запись, мобильную ширину, 12-месячный калькулятор, печать/PDF и отсутствие двойного вертикального скролла.

`index.html` — полностью автономный HTML с вшитыми стилями, JS и демонстрационными данными. `source/` — те же исходники в раздельном виде. Данные расчётов демонстрационные, не являются согласованным бюджетом. Вся комиссия считается по всем путёвкам (платным + бюджетным) помесячно, с минимумом 5 000 ₽ и исходной расчётной стоимостью 35 000 ₽. Зарплата: от 50 000 ₽. Все возможности, требующие проверки, так и маркированы.

## Интеграция и безопасность
Страница отправляет Tilda только `postMessage` о высоте и переходе между вкладками. Код T123 проверяет `event.origin`, `event.source` и `slug`. Нет сторонней аналитики и отправки введённых значений калькулятора. Ссылка на запись открывает Яндекс Диск в новой вкладке, сам файл записи в репозитории не хранится.

**Важно:** репозиторий публичный, а значит и ссылка на запись в коде будет публичной. `noindex,nofollow` не защищает от просмотра. Перед передачей ссылки заказчику проверить доступность записи и право её распространения. GitHub Pages и Tilda требуют проверки после публикации на их стороне.
