# Лагерь им. Ю. А. Гагарина — клиентский аудит CampBox

Подготовлено для GitHub Pages и встраивания в Тильду через один блок T123.

## Файлы
- `index.html` — клиентская страница по 152‑ФЗ и приказу № 201.
- `tilda-t123.html` — полный код для HTML-блока T123 в Тильде.
- `README.md` — инструкция и контроль публикации.

## Публикация на Тильде
1. Убедиться, что GitHub Pages для репозитория включён: Settings → Pages, Deploy from a branch, `main`, `/ (root)`. Если Pages уже настроен, настройки не менять.
2. Открыть ссылку GitHub Pages напрямую и убедиться, что там аудит Гагарина, а не 404.
3. В Тильде создать отдельную страницу, рекомендуемый адрес `/gagarin` (если свободен).
4. Добавить блок **T123 / HTML-код**, вставить **целиком** содержимое `tilda-t123.html`.
5. У блока в Тильде убрать внешние отступы сверху/снизу, если они есть. Не вставлять основной `index.html` напрямую в Тильду.
6. Опубликовать страницу, проверить внешнюю ссылку, вкладки 152‑ФЗ / № 201, раскрытие замечаний, смену разделов, мобильную ширину и отсутствие двойной прокрутки.
7. При последующих изменениях аудита редактировать `gagarin/index.html` и публиковать GitHub Pages; менять T123 при обычных текстовых правках не требуется.

## Как работает высота
- Клиентская страница отправляет `postMessage` с `type: campbox-audit-height`, `slug: gagarin` и текущей высотой.
- Код T123 сверяет `event.origin`, `event.source` и `slug`, затем изменяет высоту iframe.
- При переключении экранов родительская Тильда получает `campbox-audit:navigate` и прокручивает к началу блока.
- Внутри iframe отключена зависимость высоты основного контента от `100vh`, чтобы не возникал цикл растягивания.
- К странице GitHub Pages добавлен `robots=noindex,nofollow` (это не приватная защита).

## Ограничения и контроль
- Репозиторий общедоступен. Ссылку на аудит может открыть любой, кто её получил.
- Юридические замечания отражают внешнюю проверку на 03.11.2026; отдельные пункты имеют статус «нужна проверка».
- Тильда не обновляется автоматически при записи файлов в GitHub: её страницу необходимо опубликовать в редакторе вручную.
- Подтверждение публичной доступности GitHub Pages и тест после вставки в Тильду требуют браузерной проверки.
