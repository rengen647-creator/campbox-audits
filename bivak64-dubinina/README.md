1. Согласовать фактические выводы, ссылки и коммерческие условия — часть пунктов аудита имеет статус «требует проверки».
2. Слить подготовленную ветку в `main`.
3. Проверить открытую ссылку GitHub Pages, навигацию, карточки и калькулятор.
4. Вставить `tilda-t123.html` в блок T123, опубликовать, проверить десктоп и мобильную версию.
5. Финальную публикацию Tilda делать только после согласования клиентского HTML.
